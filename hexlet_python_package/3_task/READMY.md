## src/solution.py

Реализуйте функцию-предикат `scrabble`, которая принимает на вход параметра:

- набор символов (строку)
- слово.
  Функция должна проверять, можно ли из переданного набора составить это слово. В результате вызова функция возвращает `True` или `False`.

При проверке учитывается количество символов, которые нужны для составления слова, но не учитывается их регистр.

Для решения используйте встроенный инструмент — `Counter`.

### Пример

```python
scrabble('rkqodlw', 'world')  # True
scrabble('avj', 'java')  # False
scrabble('avjafff', 'java')  # True
scrabble('', 'hexlet')  # False
scrabble('scriptingjava', 'JavaScript')  # True
```

## Решение

### Проработка алгоритма

1. взять набор - преобразовать в словарь вида:
   - символ: число повторения в наборе
2. взять слово - преобразовать в словарь вида:
   - символ: число повторения в наборе
3. Дальше сравнение - какое?
4. Берем символ из слова - проверяем есть ли оно в словаре набора
   если Да - проверяем число повторений в словаре набора дб > числа повторений в словаре слова - проверяем следующий символ
   если Нет - результат False
   Для оценки возможности реализации ---> как пройти по всей коллекции.

Чтобы получить одновременно и ключи, и соответствующие значения, можно вызвать метод `.items()`:

```python
for k, v in {"a": 1, "b": 2}.items():
    print(k, "=", v)
```

Итак реализуем п.1. - превратить строку в словарь ---> `Counter`
